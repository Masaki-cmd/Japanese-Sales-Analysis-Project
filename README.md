# Japanese-Sales-Analysis-Project
# Sales Data Analysis Project (Japanese)

## 概要

このプロジェクトは、提供された販売データセットを用いて、収益向上とコスト最適化を目指すデータ分析を行いました。

**最終評価指標 (KGI):** 収益の最大化およびコストの最適化

## 分析プロセスと結果

### 1. データ読み込み

*   `archive (1).zip`を解凍し、以下のファイルが特定され、Pandas DataFrameとして読み込まれました。
    *   `Updated_sales.csv`
    *   `Sales_Data`フォルダー内の2019年の月別販売データ（`Sales_April_2019.csv`など）
*   月別ファイルは`df_monthly_sales`として結合されました。

### 2. データクリーニングと特徴量エンジニアリング

読み込んだ初期データには以下の課題がありました：
*   全てが`object`型で、`NaN`値が含まれる。
*   複数のCSVを結合した際に、ヘッダー行がデータとして誤って読み込まれている。

**実施したクリーニング手順:**
1.  `Order ID`が`NaN`の行を削除。
2.  `Order Date`カラムに`'Order Date'`という文字列が含まれる行（誤って読み込まれたヘッダー行）を削除。
3.  `Quantity Ordered`を`int`型に、`Price Each`を`float`型に、`Order Date`を`datetime`オブジェクトに変換。
4.  型変換後に発生した`NaN`値を含む行を再度削除。

**追加した特徴量:**
*   **`Sales`**: `Quantity Ordered * Price Each`で計算。
*   **`Month`**: `Order Date`から月を抽出。
*   **`Hour`**: `Order Date`から時間を抽出。
*   **`City` および `State`**: `Purchase Address`から都市と州を抽出。

### 3. 分析結果と提案

#### 3.1. 全体的な売上トレンド (月ごと)

*   **発見:** 12月、10月、4月が売上ピークで、1月、8月、9月が低い季節性が見られました。
*   **提案:** 低需要期（1月、8月、9月）にはプロモーションを強化し、ピーク期にはリソース（在庫、人員）を最適化することで、機会損失を防ぎます。

#### 3.2. 全体的な売上トレンド (時間ごと)

*   **発見:** 午前中（9時〜12時）と夕方以降（17時〜20時）に売上が集中しています。
*   **提案:** 売上ピーク時間帯に合わせて広告やプロモーションを集中させ、人員配置を最適化することで、顧客体験と販売効率を向上させます。

#### 3.3. 製品パフォーマンス

*   **発見:** Macbook Pro LaptopやiPhoneなどの高価格帯製品が売上総額に大きく貢献。AAA BatteriesやUSB-C Charging Cableなどのアクセサリー類は販売数が多いものの、個別売上貢献は低い傾向があります。
*   **提案:** 高価格帯製品とアクセサリーのバンドル販売を強化し、製品ポートフォリオの最適化、ターゲットマーケティングを行います。

#### 3.4. 地域別売上パフォーマンス

*   **発見:** サンフランシスコ、ロサンゼルス、ニューヨークシティが売上上位の都市でした。
*   **提案:** 主要都市への集中投資を継続し、低売上地域の市場調査を行い、物流ネットワークの最適化を検討します。

#### 3.5. 顧客行動パターン (共起商品)

*   **発見:** iPhoneとLightning Charging Cable、Google PhoneとUSB-C Charging Cableなど、主要デバイスとアクセサリーの間に強い共購入パターンが見られます。
*   **提案:** バンドル販売の推進、オンライン/店頭での商品配置の最適化、パーソナライズされたマーケティング、関連商品の在庫同期により、顧客単価の向上と販売機会の最大化を図ります。
